# Problem statement

## Client context

- **Delivery organisation:** Zynx Technologies Ltd
- **Domain client:** Digital / AI Client
- **Engagement type:** Solution Architecture Delivery

## Business problem

The Digital / AI Client wanted an agentic analytics pattern where natural-language questions can be routed to specialised SQL or ETL agents with explicit state contracts, validation, and human-governed implementation guidance.

## Success criteria (engagement)

- Clear architecture and ownership model
- Inspectable artefacts in Git (docs, diagrams, code/notebooks)
- Domain-safe documentation suitable for public portfolio audit
- Handover path for client engineering teams
